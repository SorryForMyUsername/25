# Задание 3. 
Создать класс библиографических описаний книг CBookCard. В классе должны быть закрытые поля: автор, заглавие, издательство, год издания, число страниц, тираж, рейтинг от 0 и до 100 и комментарий к книге. Для полей должны быть созданы методы доступа, конструктор, инициализирующий поля кроме рейтинга и комментария. Создать метод выводящий данные о книге в строку и тираж с рейтингом должны выводиться через двоеточие (тираж: значение и рейтинг: значение ).
